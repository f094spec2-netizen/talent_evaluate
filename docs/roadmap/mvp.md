# MVP 实施路线

## 1. MVP 目标

首版先解决事实核验和报告复用，不自动决定最终人才等级。建议选择 2–3 个公司进行 4 周试点。

## 2. 分阶段交付

### Phase 0｜治理与样本（约 1 周）

- 确认项目负责人、试点范围、角色与权限；
- 冻结首版上传规范、证据等级及红黄绿规则；
- 准备脱敏测试样本与真实资料授权方式；
- 定义验收指标与现行人工流程基线。

### Phase 1｜接入与事实底座（约 2–3 周）

- Telegram 私聊接入、身份白名单与文件收件；
- 文件格式、MIME、大小、哈希、版本校验；
- Excel／Word／HTML 首批解析器；
- 人员与项目主数据、别名及日期／周次核对；
- PostgreSQL 任务队列、对象存储与审计。

### Phase 2｜总管与专业处理（约 2–3 周）

- 总管状态机、依赖、重试与失败恢复；
- 资料收集、身份归档、项目去重和贡献核验 Agent；
- 红黄绿分流及 Telegram 一键确认；
- 周报／月报自动汇总与差异说明。

### Phase 3｜人才证据与校准（约 3–5 周）

- 能力定义、能力变化候选和稳定性证据；
- 学习事件、潜力趋势与“无法判断”机制；
- 独立审核、管理校准和评估版本；
- 质量、偏差、成本与管理价值复盘。

## 3. MVP 验收指标

| 维度 | 建议指标 |
|---|---|
| 收件 | 应收资料状态准确率、重复文件识别率 |
| 期间 | 日期／周次归档准确率 |
| 身份 | 人员与公司自动匹配率、人工修正率 |
| 项目 | 跨周／跨月重复项目识别准确率 |
| 证据 | 结论可追溯率、无证据结论数 |
| 效率 | 效能官每周额外文字工作时间下降比例 |
| 稳定性 | 任务成功率、重试率、平均处理时间 |
| 成本 | 单文件与单评估批次的平台／模型成本 |

准确率指标必须用人工标注样本验证，不能以 Agent 自评信心替代。

## 4. 领导与效能中心需配合

- 指定一名效能中心项目负责人和最终业务负责人；
- 确认试点公司、应收资料清单及项目系统接入方式；
- 强制执行文件命名、期间、版本和最低字段规范；
- 指定效能官在约定时限内确认黄色异常；
- 确认哪些事项可自动归档、哪些必须管理者决定；
- 核准 Railway、模型 API、资料保存地区与月度预算；
- 批准真实人员资料的访问者、保留期、下载与删除流程。
